# RecruitFlow documentation

This directory is the engineering documentation set for RecruitFlow. It describes the implemented system, its database contract, lifecycle rules, operational commands, validation evidence, and known limitations.

## Reading order

1. [PROJECT_OVERVIEW.md](PROJECT_OVERVIEW.md) — scope, users, and implementation status.
2. [SYSTEM_ARCHITECTURE.md](SYSTEM_ARCHITECTURE.md) — runtime components and request flow.
3. [DATABASE_SCHEMA.md](DATABASE_SCHEMA.md) and [data_dictionary.md](data_dictionary.md) — persistence model.
4. [MODULE_DOCUMENTATION.md](MODULE_DOCUMENTATION.md) — backend modules and business rules.
5. [RECRUITMENT_WORKFLOW.md](RECRUITMENT_WORKFLOW.md) — lifecycle and valid transitions.
6. [API_DOCUMENTATION.md](API_DOCUMENTATION.md) — FastAPI route reference.
7. [DATA_GENERATION_AND_REPRODUCIBILITY.md](DATA_GENERATION_AND_REPRODUCIBILITY.md) — synthetic data and safe generation.
8. [ANOMALY_SCENARIOS.md](ANOMALY_SCENARIOS.md) — labelled challenge fixtures.
9. [TESTING_AND_VALIDATION.md](TESTING_AND_VALIDATION.md) — test architecture and recorded evidence.
10. [SECURITY_AND_CONFIGURATION.md](SECURITY_AND_CONFIGURATION.md) — secrets, authentication, and security controls.
11. [SETUP_AND_EXECUTION.md](SETUP_AND_EXECUTION.md) — Windows and PowerShell setup.
12. [TECHNICAL_DECISIONS.md](TECHNICAL_DECISIONS.md) — rationale and trade-offs.
13. [VALIDATION_AND_LIMITATIONS.md](VALIDATION_AND_LIMITATIONS.md) — detailed validation record and limitations.
14. [source_manifest.md](source_manifest.md) — provenance of generated exports.
